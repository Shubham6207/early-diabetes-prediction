# GlycoSight — Early diabetes prediction

Repository: [Shubham6207/early-diabetes-prediction](https://github.com/Shubham6207/early-diabetes-prediction)

Static educational website that estimates type 2 diabetes risk from eight clinical markers using a **logistic regression** model (PIMA-style coefficients) and a small **threshold ensemble** for comparison.

Open `index.html` in a browser. Nothing is uploaded; scoring runs locally.

This is not medical advice.
