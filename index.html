Why early prediction

Diabetes often develops years before a diagnosis.

Type 2 diabetes can stay silent while glucose regulation slowly fails. Catching elevated risk from simple clinic values — fasting glucose, BMI, blood pressure, family-history style pedigree, age — gives people time to change diet, activity, and follow-up before complications set in.

Machine learning is useful here because the relationship is multivariate. No single number is enough: a moderately high glucose with obesity and a strong pedigree is a different story than the same glucose in a younger person with a healthy BMI.

Screen, don’t diagnose

Models like this rank risk. A clinician still confirms with fasting plasma glucose, HbA1c, or an oral glucose tolerance test.

Cheap features

The eight PIMA-style markers are already collected in many check-ups, so the model can run without extra lab panels.

Transparent weights

Logistic regression shows which inputs push risk up. You can inspect coefficients instead of treating the model as a black box.

Pipeline

From raw measurements to a probability.

  1. Collect features

    Pregnancies, glucose, blood pressure, skin thickness, insulin, BMI, diabetes pedigree function, and age.

  2. Standardize

    Each value is z-scored with the training mean and standard deviation so coefficients are on a comparable scale.

  3. Score two models

    Logistic regression produces a calibrated probability. A compact random-forest style ensemble of threshold rules is shown as a second opinion.

  4. Explain

    Feature contributions (weight × z-score) are ranked so you can see what drove the estimate.

Limits

Built for learning, not the clinic.

The Pima Indians Diabetes dataset is a classic teaching set. It is small, historically specific, and contains placeholder zeros for missing labs. A production screener would be retrained on local, diverse, prospectively collected data and validated against HbA1c or fasting glucose outcomes.

GlycoSight runs entirely in your browser. Nothing you type is uploaded. Treat every output as a demonstration of how logistic regression and simple ensembles score diabetes risk.
